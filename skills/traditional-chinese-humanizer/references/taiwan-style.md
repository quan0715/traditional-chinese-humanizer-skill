# Taiwan Traditional Chinese style

Use this reference when a draft includes Simplified Chinese, PRC phrasing, translated English structure, or mixed regional vocabulary.

## Script and vocabulary

Use Traditional Chinese. Prefer Taiwan common usage when choices differ.

| Avoid | Prefer |
| --- | --- |
| 通过 | 透過 / 經由 / 用 |
| 支持（系統功能語境） | 支援 |
| 信息 | 資訊 |
| 用户 | 使用者 |
| 质量 | 品質 |
| 创建 | 建立 |
| 查看 | 檢視 / 查看（依語境） |
| 优化 | 優化 |
| 数据 | 資料 / 數據（依語境） |
| 项目 | 專案 / 項目（依語境） |
| 屏幕 | 螢幕 |
| 默认 | 預設 |
| 反馈 | 回饋 |
| 服务器 | 伺服器 |
| 软件 | 軟體 |
| 发布 | 發布 / 上線（依語境） |
| 运营 | 營運 / 經營 |

## Translationese

Rewrite direct English structures into natural Chinese.

| Awkward | Better |
| --- | --- |
| 這允許使用者... | 使用者可以... |
| 這有助於提升... | 這能提升... / 因此... |
| 其提供了一個... | 它提供... / 這項功能提供... |
| 進行一個檢查 | 檢查 |
| 做出一個決定 | 決定 |
| 對於使用者來說 | 對使用者而言 / 使用者... |
| 基於...的原因 | 因為... |

## Technical terms

Do not force-translate terms that professional readers expect in English:

- `API`, `OAuth`, `SDK`, `CLI`
- `edge case`, `spec`, `pipeline`, `token`, `prompt`
- `KPI`, `OKR`, `SOP`

If a Chinese term is clearer and common, use Chinese:

- `採購週期`
- `監考流程`
- `鑑別度`
- `學習歷程`
- `權限控管`

Use one term consistently inside the same document.

## Tone

Professional Traditional Chinese should be precise before it is polished.

- Use `協助`, `支援`, `提供`, `整理`, `標示`, `追蹤`, `比對`, `檢視`, `降低`, `縮短`.
- Be careful with `打造`, `賦能`, `顛覆`, `革新`, `重塑`, `全方位`.
- Do not add idioms or literary phrasing just to sound human.
- Prefer a clear short sentence over a beautiful vague one.
